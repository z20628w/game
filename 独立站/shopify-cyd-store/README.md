# CYD 商城 Shopify 主题

参考 CYD 小程序的消费者商城。沿用品牌标志、两张原版轮播图、系列入口、双列商品卡和收藏交互。桌面端用并排的图片与文案，手机端用纵向主视觉和底部导航。此目录是独立项目，主题代码位于 `theme/`，新增的 Liquid、CSS、JavaScript 含中文注释。

[开发店铺预览](https://cyd-theme-lab.myshopify.com/) · [Shopify 主题编辑器](https://admin.shopify.com/store/cyd-theme-lab/themes/155681554510/editor)。当前测试主题 ID 为 `155681554510`。

## 开发与检查

```powershell
npm ci
npm run check
npm run dev
npm run package
```

使用 Node.js 22.12 或以上。开发命令连接开发店铺 `0e80cm-rd.myshopify.com`，需要有主题访问权限。跨店使用时替换店铺参数。更新远端预览时，请先确认预览主题的 ID，再用 Shopify CLI 指定该 ID。结账、账户、支付和物流继续使用 Shopify 自己的服务。

## 页面与后台设置

| 页面或功能 | 主题负责 | 后台如何配置 |
| --- | --- | --- |
| 首页 | 主视觉轮播、最新系列、商品卡与快捷加购 | 主题编辑器的 CYD 区块可换图片、文案、关联商品和系列 |
| 导航 | 桌面菜单、手机底栏、搜索框、账户与购物车入口 | 可在页眉指定菜单；未选时显示首页、系列和商品列表。可在主题设置关闭底栏 |
| 系列与商品列表 | 系列图、双列或多列商品卡、筛选和排序 | 商品、系列和图片在 Shopify 商品后台维护；筛选维度由店铺配置决定 |
| 商品详情 | 图册、SKU、规格、价格、数量、加购与快捷结账入口 | 维护商品规格、媒体、价格和库存；可在商品模板调整显示区块 |
| 搜索与购物车 | Shopify 商品搜索；购物车抽屉、购物车页和结账入口 | 购物车展示类型可在主题设置切换，付款和配送规则由店铺配置 |
| 收藏 | 当前浏览器的收藏列表与商品卡状态 | 可在主题设置关闭；此功能不会同步到用户账户或其他设备 |
| 内容与反馈 | 普通页面、政策链接、Shopify 联系表单模板 | 建立对应页面、填写真实政策；需要反馈页时给页面选择 `contact` 模板并加入导航 |

## 数据来源

主题使用 Shopify 的 Liquid 对象、商品表单、搜索路由和原生购物车请求。图片通过主题资产或 Shopify 商品媒体展示，**页面运行时不连接小程序后台，也不调用小程序接口**。

开发店铺的精选样本单独放在 `catalog/cyd-preview-products.json`。图片及商品名用于预览，美元金额和可售状态用于测试，与小程序正式售价、库存无关。预览默认显示 CYD 专用商品系列；迁到没有这些样本的店铺时，可通过主题编辑器选择实际商品和系列。

`npm run seed:preview` 只显示本地导入清单。向当前店铺导入时运行 `npm run seed:preview -- --store cyd-theme-lab.myshopify.com --apply`。脚本通过 Shopify Admin API 创建 8 件带演示标记的商品、13 个规格和 3 个系列，并启用在线商店渠道。目标店铺需使用美元、默认语言为英语且已发布简体中文。商品与系列已存在时会复用，补齐缺少的系列关联和中文译文。

原始中文资料位于 `catalog/cyd-preview-products.json`，英文对照位于 `catalog/cyd-preview-copy.json`。译文通过 Shopify 原生翻译功能保存，覆盖商品标题、正文、类型、规格名称、规格值和可翻译的图片替代文字。原始图片地址仅用于 Shopify 导入媒体，店面读取 Shopify 托管图片。价格与可售状态是测试样本。在同一店铺内，各主题共享商品和系列。
