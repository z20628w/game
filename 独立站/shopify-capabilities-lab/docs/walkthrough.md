# UI 与产品体验路线

先从 [预览首页](https://0e80cm-rd.myshopify.com/?preview_theme_id=189084696894) 进入，后续使用页面顶部实验室导航，保留同一浏览器的预览会话。

在页面或购物车抽屉展开「可自定义」，可以查看当前功能由主题编辑器、主题代码、后台配置、应用扩展或平台处理的部分。演示标注可在主题编辑器的「主题设置 → 能力实验室」中关闭。店铺内容、托管结账和客户账户的语言取决于各自的后台设置。

## 1. 主题能力速查

首屏按「主题能直接做」「需要特殊方法」「主题做不了」给出典型示例。点击其中一类可筛选功能对照表，也可按关键词和功能分类查找全部 46 项。每行直接给出实现方式或前置条件，展开后可查体验步骤、代码位置和官方依据。评审结论描述实现边界，实测情况以验收记录为准。

从首屏或导航进入「海外市场要求」，按市场查看规则的适用范围、页面或流程要求、Shopify 实现思路与官方依据。该页用于产品评审，实际实施前按经营角色、商品类别和目标市场复核。

从导航打开「界面设计」，先用页面顶部的 UI 设计速查表比较可调整的位置、平台边界、现成配置和开发工作。每行链接跳到对应演示。购物车可比较左右抽屉、居中弹窗、底部面板和独立页。商品和集合替代模板分别展示媒体位置、规格控件、列数、加购和筛选布局。导航与搜索示例使用实际链接和搜索结果。结账模块提供单页与三页的步骤对照，可从真实购物车进入店铺当前结账。

修改默认商品或集合模板后，运行 `npm run guide` 可重新生成对应的演示模板。

## 2. 商品与购物车

进入演示商品集合，体验排序、商品详情、颜色切换、折扣价和售罄状态。陶瓷杯第三个颜色有不同价格。输入“演示验收”等定制文字后加购，在购物车查看行属性，再调整数量和移除。

定制文字不自动加价。测试商品可售款不跟踪库存，售罄笔记本启用库存跟踪并维持零库存。只有这批测试商品使用此设置，不代表真实店铺库存方案。

过滤器需 Search & Discovery 配置，推荐商品依赖推荐数据或手工配置。测试支付与配送未配置时，不把能进入结账页面等同于能成功完成订单。不要对演示商品进行真实付款。

## 3. 收藏与对比

在两个商品页分别点击加入本机收藏，进入收藏对比查看价格、规格和状态。刷新页面后仍可读取；移除或清空后立即更新。上限 6 件，数据仅存于该浏览器，不跟随 Shopify 账号跨设备同步。

## 4. 自定义数据

打开“自定义数据”，对照后台的商品材质、特点列表和保养指南。修改后台字段并刷新预览，可验证数据与主题相互独立。

Metafield 为商品等资源增加字段；Metaobject 定义独立结构，创建条目后可由多个商品引用。主题既演示商品引用读取，也演示通过 type + handle 全局读取。

## 5. 接口实验

分别请求商品、当前购物车、预测搜索和区块渲染。页面展示真实响应摘要及失败提示，不展示购物车 token。数据以当前浏览器会话和店面语言/市场为准。请求是只读的，商品与购物车内容仍由 Shopify 返回。

## 6. 组件实验

进入主题编辑器，切换首页替代模板 `lab-components`。调整主题块标题，重排卡片，展开折叠内容；按需添加 Dawn 的图文、幻灯片或视频区块。上传素材后才能验证视频和 3D 等媒体效果。

## 7. 需求评审

打开“能力边界”，逐项确认需求属于主题展示、后台配置、应用扩展还是不允许的实现方式。UI 设计需覆盖正常、空数据、加载、失败、售罄、不可选规格和移动端状态。

产品评审要明确：数据维护位置、权限、定价规则、跨设备需求和后台业务流程。开发据此确定主题区块、数据定义与必要扩展，而不是提前把所有应用能力列为主题自带功能。
